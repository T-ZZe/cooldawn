# CooldownPlugin

Plugin Paper (Minecraft Java 26.3) :
- Perle de l'Ender : cooldown de 5 secondes
- Mace : cooldown de 8 secondes

## Compilation
    mvn clean package
Le jar se trouve dans `target/CooldownPlugin-1.0.0.jar` : mets-le dans le dossier `plugins/` du serveur.

Prérequis : Java 21+ et Maven.
